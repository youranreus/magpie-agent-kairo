# Changelog

## 0.2.0

- Export all models and routing groups Magpie exposes to Kairo, so compatible Kairo builds list them without manual synchronization or per-model selection.
- Display the existing Kairo application icon on the Agent row and plugin card, embedded for offline use.
- Keep the default model separate from the catalog and retain compatibility with older single-model bridge writers.

## 0.1.0

- Initial Kairo Agent integration with a versioned gateway configuration bridge.
